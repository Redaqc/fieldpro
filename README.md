# FieldPro - Field Service Management System

A comprehensive Field Service Management application built with React, Vite, and Base44.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 📚 Documentation

- **Setup Guide**: See `SETUP.md` for complete installation and configuration
- **Database Schema**: See `DATABASE_SCHEMA.md` for entity definitions
- **Features**: 39 modules including Jobs, Schedule, Invoices, GPS Tracking, and more

## ⚠️ Important: Database Setup Required

Before running the app, create these critical entities in Base44 Dashboard:

1. **PushSubscription** (Required for push notifications)
2. **BrandingSettings** (Optional for custom branding)

See `SETUP.md` and `DATABASE_SCHEMA.md` for detailed instructions.

## 🔧 Tech Stack

- React 18 + Vite 6
- Base44 SDK (BaaS)
- TailwindCSS + Shadcn/ui
- React Query
- React Router v6

## 📦 Features

- ✅ 39 complete modules
- ✅ Mobile-first design with offline support
- ✅ Working hours validation for schedule
- ✅ Push notifications
- ✅ GPS tracking with geofencing
- ✅ Stripe payments integration
- ✅ Multi-language (FR/EN)
- ✅ Role-based permissions

For more information, see `SETUP.md`
